# 身份判断小规模诊断集 v1

本集用于定位身份证据、裁决和接受门槛的问题，不能作为全文准确率或独立留出成绩。两本小说已参与开发。32 对提及由 Codex 阅读原文核对，**尚未经独立人工复核，不是人工金标准**；标签版本与来源指纹随文件冻结。

## 文件和口径

- [inputs.json](inputs.json)：输入文件指纹、Unicode 码点地址、两个目标提及、已有发现给出的暂定类别及原文关系证据地址。在线请求只读取这些输入及小说正文。
- [reference/labels.json](reference/labels.json)：同一／不同标签、逐条原文依据、理由、核对来源及待独立复核状态。只供评分，不能送入模型。
- [实验工具](../../tools/identity_calibration.py)：只读历史库重放或受预算约束的在线实验；不修改生产门槛、历史任务、提及和分组。
- 原小说作者、来源与许可沿用[文本库说明](../text-library/README.md)和[来源声明](../text-library/provenance/NOTICES.md)。

标注单位是两个明确地址的目标所指，不是字符串是否相似。所有格中的人名按持有人标注，不能把人名自动当成其房屋；同一出现位置的完整姓名与其中简称可指同一对象，但另标 `overlap`，不能据此宣称发现边界合理。不同位置的同一称谓可能指不同人。不能只依据同名、同类、亲属关系或邻文共现标为同一。

| 队列 | 中文 | 英文 | 同一／不同 | 用途 |
| --- | ---: | ---: | ---: | --- |
| p01—p24，历史配对 | 10 | 14 | 12／12 | 都有单提及组的初判与扩证据响应，比较两种上下文及固定响应上的门槛 |
| p25—p32，额外挑战 | 4 | 4 | 3／5 | 不以历史响应齐全为筛选条件；额度恢复后已完成两次在线证据对照 |
| 合计 | 14 | 18 | 15／17 | 全部为诊断／回归用途，没有独立留出集 |

配对队列按称呼、原文位置、问题类型和响应可用性选取，在核对标签时未按模型选项或分数筛选。但是，历史上只有低分／未接受的比较才扩证据，因此队列天然偏向困难例。原始模型选择本来正确的样本也保留，检查扩证据后是否退步。不能由这个队列估算全书待审率。额外 8 对不是独立留出，不得从全体 32 对中静默删除后报告“32 对准确率”。

## 固定实验条件

固定 `jev-1.13.0`、同一身份提示与选项、目标、暂定类别、每边一个代表及额外关系证据；分别读取目标前后 180／400 个 Unicode 码点。两种语言的相同码点数不等于相同单词数或语义容量。标注依据可能比模型窗口更长，但额外人工标注依据不进入模型。

固定分数网格为概率 `0.95 / 0.90 / 0.85 / 0.80 / 0`，置信度 `0.8 / 0.7 / 0`。`0 / 0` 仅用于看模型原始选择；`uncertain` 仍不当作自动接受。所有门槛使用完全相同的响应，不为某个错例反复改问直到高分。

评分分别报告正确、错误、待审、未测；自动裁决准确率＝正确／放行数，覆盖率＝放行数／队列大小。误合并与错误判不同分别列出。合并召回分母保留全部已标注同一对，未决不算正确合并。证据工具测单次裁决；后文新增工具调用完整单候选复核，**两者都不包含多成员组、竞争候选及整书归组的反事实效果**。

历史重放核验两个目标及前后文逐字等于原文，实际 HTTP 状态等于保存证据，选项和响应对应，固定字段没有随窗口改变。22 对曾处于多问题批次，同批其他问题可变化；只有 2 对两次请求均为单问题。因此历史结果自身不能排除批次因素；新的单问题对照单独报告，不回写成历史实验已控制这些因素。

## 重放和恢复

历史重放只需本机既有数据库，不需要密钥或网络；缺少原始历史记录时会失败，不用模拟答案补齐。

```powershell
python tools/identity_calibration.py replay --out outputs/identity-calibration/replay.json --summary-out outputs/identity-calibration/summary.json
```

新在线入口每次只发一个样本，交替 AB／BA 顺序，第二次重复倒转顺序；每次重复创建新的响应缓存数据库。标签文件完全不由在线入口读取。默认 24 对 × 2 个窗口 × 2 次独立重复，共最多 96 次尝试；串行、每次最多 45 秒、总调用窗口 600 秒、无重试。硬额度或预算耗尽立即停止，缺失回答单列，不冒充模型的“不确定”。已有回执或重复数据库不会被覆盖。截止时间限制新请求及单次网络 timeout，操作系统网络中断时刻不是实时硬截止保证。

2026-10-29 用户解决余额问题后，以下单问题在线实验已完成。需要再次验证时使用新的输出文件名；重复执行会产生模型费用。

```powershell
python tools/identity_calibration.py online --out outputs/identity-calibration/online-01.json --cohort cached_paired --repeats 2 --max-requests 96 --max-seconds 600
```

`--cohort challenge_unmeasured` 可单独验证另 8 对（名称保留历史数据版本，现已在线测量）；`--cohort all --repeats 1` 可覆盖 32 对，但与默认两次重复的设计不同，必须单独记账。本次主队列 96 次、挑战队列 32 次请求均成功。在线结果由独立的评分步骤读取标签；即使中断也保留所有缺失问题，不把错误或未测记为正确。评分不自动更改生产门槛。

```powershell
python tools/identity_calibration.py score --answers outputs/identity-calibration/online-01.json --out outputs/identity-calibration/online-01-score.json
```

## 完整单候选复核实验

[identity_chain_experiment.py](../../tools/identity_chain_experiment.py) 将每对输入建立为两个单提及组，直接调用生产 `resolve_task`。对照 0.95／0.90 概率门槛，置信度均为 0.8；保留扩证据、正反关系复核和条件触发的类别检查。没有多候选竞争，不能代替全书归组实验。

每个门槛使用独立新数据库，按样本交替先后次序；串行、无重试、45 秒 timeout，最多 256 次尝试／900 秒。临时门槛只作用于独立的实验进程，不应在并发业务服务中导入调用；异常也恢复原门槛。模型响应和原文缓存留在忽略的输出目录；标签只在 `score` 读取。

```powershell
python tools/identity_chain_experiment.py online --out outputs/identity-calibration/chain-01.json
python tools/identity_chain_experiment.py score --answers outputs/identity-calibration/chain-01.json --out outputs/identity-calibration/chain-01-score.json
```

本次两组各 68 次请求，0.95／0.90 最终正确自动处理 3／12 对、错误均 0、待审 29／20。生产默认值未改；少量开发样本尚不足以支持上线门槛。
